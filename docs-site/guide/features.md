# Features

- **Generate docs from code** — CLI + dashboard button scans README, exports, routes.
- **Slack / Discord alerts** — incoming webhooks on new drift flags + test send.
- **Version history** — list, diff, rollback (creates a new version).
- **Team on drift** — assignees, comments, filter by assignee.
- **Test runner ingest** — JUnit XML → drift when covered code/tests fail.
- **Multi-repo overview** — ok / stale / in-review counts per project.
- **Unified search** — docs + code FTS5 with `search_all` MCP tool.
